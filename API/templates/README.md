# Etap 2 — szablony API (wersja robocza)

Nie stosować bezpośrednio przez kubectl. Go text/template, missingkey=error; walidować wszystkie parametry przed renderowaniem, a następnie wykonać server-side dry-run. Nie przyjmować dowolnych manifestów platformowych od klienta.

Namespace: DNS label maks. 57 znaków (Schedule z sufiksem -daily). RouteName: unikalna nazwa per domena, maks. 48 znaków; Domain: zweryfikowana nazwa DNS bez wildcard. BackendService i AppLabel: poprawne nazwy/etykiety; BackendPort i ContainerPort: 1–65535; CPU, Memory, Storage: dodatnie Kubernetes quantities; PVLimit: nieujemna liczba całkowita; RateLimitRPS: dodatnia liczba całkowita. ListenerName i TLSSecret wyznacza API. Nie renderować surowych danych bez walidacji.

Kolejność: namespace, quota, RBAC (default SA po jego utworzeniu przez kontroler), network policy, backup; opcjonalny Helm po walidacji. Service tylko gdy potrzebny i znany selektor, nie duplikować Service Helm. Routing tylko dla znanego backendu. Certyfikat prod albo staging, nie oba; TLSSecret zgodny z nazwą secretName. ReferenceGrant i listener HTTPS dodaje API po wydaniu certyfikatu. Gateway HTTP musi dopuszczać namespace klienta i ACME solver; listener HTTPS z hostname domeny i certificateRefs z namespace klienta. Aktualizacja współdzielonego Gateway wymaga kontroli współbieżności i własności domen. Przekierowanie HTTP dopiero po weryfikacji ACME. Brak gotowego backendu nie oznacza gotowego hostingu.

Rate limit lokalny per proxy/per reguła; schemat CRD sprawdzić w klastrze. Timeout i retry z pierwotnego manifestu pominięte celowo (nie narzucać 5s i ponawiania operacji). Backup zachowuje harmonogram i retencję, nie potwierdza skuteczności snapshotów. Nie dodano LimitRange bez uzgodnienia domyślnych limitów per kontener. RBAC bez Role/RoleBinding dla workloadów. Helm musi blokować nadpisywanie zabezpieczeń, automount tokenów i niedozwolone zasoby; sama NetworkPolicy nie gwarantuje izolacji hostów/NAT. Zweryfikować politykę w klastrze. StorageClass wymuszać przy walidacji PVC, nie tworzyć pustego PVC automatycznie.
